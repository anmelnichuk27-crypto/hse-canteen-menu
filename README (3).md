# Помощник для выбора обеда в столовой НИУ ВШЭ

## О проекте
В обеденный перерыв в столовой университета много людей, а времени на выбор мало. Студенту нужно быстро понять, что сегодня в меню, какие блюда входят в комплексный обед и сколько в итоге придётся заплатить. Дополнительная сложность возникает у тех, кому нельзя есть некоторые продукты, например при непереносимости лактозы: им приходится самостоятельно проверять каждое блюдо.

Комплексный обед выгоднее, чем покупка тех же блюд по отдельности, но не всегда очевидно, получился ли комплекс и какая цена будет применена, если одно из блюд выбрано не из него.

Цель данного проекта — с помощью языка Python создать программу, которая помогает собрать обед с учётом меню на конкретный день и ограничений в питании, автоматически определяет тип комплексного обеда и рассчитывает итоговую стоимость заказа.

## Данные, используемые в программе
Все данные заданы вручную внутри кода в виде словарей и списков.

**Меню (`menu`)** составлено на шесть дней недели — с понедельника по субботу. На каждый день в нём есть четыре категории блюд:
- салаты;
- супы;
- вторые блюда;
- компоты и напитки.

В каждой категории по три блюда. Одно из них отмечено пометкой «(комплекс)» и входит в комплексный обед.

**Цены (`PRICES`)** на блюда вне комплекса:
- салат — 120 руб.;
- суп — 100 руб.;
- второе блюдо — 200 руб.;
- компот — 50 руб.

**Цены комплексных обедов:**
- полный комплекс (4 блюда) — 350 руб.;
- частичный комплекс (3 блюда) — 320 руб.

**Список блюд с лактозой (`LACTOSE_DISHES`)** содержит блюда, в состав которых входят молочные продукты (например, Цезарь, Борщ, Лазанья, Сырный крем-суп, Паста Карбонара).

## Как работает программа
1. Пользователь выбирает день недели, и программа показывает меню на этот день.
2. Программа спрашивает, есть ли у пользователя непереносимость лактозы. Если есть, функция `filter_lactose_dishes()` убирает из меню блюда, содержащие молочные продукты.
3. Пользователь выбирает по одному блюду из каждой категории.
4. Программа считает, сколько выбранных блюд входит в комплекс:
   - если все 4 блюда из комплекса, заказ стоит 350 руб.;
   - если 3 блюда из комплекса, стоимость составляет 320 руб. плюс цена четвёртого блюда;
   - если блюд из комплекса меньше трёх, каждое блюдо считается по отдельной цене.
5. Пользователь выбирает способ оплаты (наличные, карта или QR-код).
6. Итоговая сумма сохраняется в файл `сумма.txt`.

Программа сделана в двух вариантах. В консольной версии (`main.py`) пользователь вводит ответы с клавиатуры, а программа проверяет, что введено допустимое значение. В веб-версии (`app.py`) на библиотеке Streamlit выбор делается через выпадающие списки и кнопки в браузере.

## Ограничения
Программа является учебной моделью и имеет ряд ограничений:
- Меню и цены записаны прямо в коде, поэтому для их изменения нужно редактировать файл.
- Наличие лактозы определяется по названию блюда, а не по составу. Если в меню появится новое блюдо, его нужно вручную добавить в список `LACTOSE_DISHES`.
- Учитывается только одно ограничение в питании. Другие (глютен, орехи, вегетарианство) пока не предусмотрены.
- Оплата только имитируется и не связана с настоящими платёжными системами.

В дальнейшем программу можно развить: хранить меню в отдельном файле (например, CSV), добавить другие ограничения в питании и историю заказов.

## Структура репозитория
- `main.py` — консольная версия программы.
- `app.py` — веб-версия программы на Streamlit.
- `hse-caffe.ipynb` — Jupyter Notebook, в котором разрабатывался и проверялся код.
- `requirements.txt` — список необходимых библиотек (streamlit).

## Как запустить
1. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите консольную версию:
   ```bash
   python main.py
   ```
   или веб-версию (она откроется в браузере):
   ```bash
   streamlit run app.py
   ```
