## Описание

Программа помогает студентам и сотрудникам быстро собрать обед. Пользователь указывает день недели и ограничения по питанию, выбирает блюда из каждой категории, а программа сама определяет, сложился ли комплексный обед, и рассчитывает итоговую стоимость.

Проект реализован в двух версиях с одинаковой логикой: консольной (`main.py`) и веб-приложении на Streamlit (`app.py`).

## Функциональность

- Меню на шесть дней (понедельник–суббота) в четырёх категориях: салаты, супы, вторые блюда, напитки.
- Исключение из меню блюд, содержащих лактозу, если у пользователя есть непереносимость.
- Автоматическое определение полного или частичного комплексного обеда.
- Расчёт итоговой стоимости заказа.
- Выбор способа оплаты: наличные, банковская карта, QR-код.
- Сохранение итоговой суммы в файл `сумма.txt`.

## Требования

- Python 3.9 или новее
- Библиотеки из `requirements.txt` (Streamlit нужен только для веб-версии)

### Консольная версия

```bash

```

```bash

```

Приложение откроется в браузере по адресу `http://localhost:8501`.


### Порядок действий

1. Выберите день недели.
2. Укажите, есть ли непереносимость лактозы.
3. Выберите по одному блюду из каждой категории.
4. Проверьте расчёт стоимости.
5. Выберите способ оплаты.

## Логика расчёта стоимости

Блюда, входящие в комплексный обед, отмечены в меню пометкой «(комплекс)». Стоимость зависит от того, сколько таких блюд в заказе:

| Состав заказа | Стоимость |
|---|---|
| 4 блюда из комплекса | 350 ₽ |
| 3 блюда из комплекса | 320 ₽ + цена четвёртого блюда по прайсу |
| Менее 3 блюд из комплекса | сумма цен всех блюд по прайсу |

Цены блюд вне комплекса:

| Категория | Цена |
|---|---|
| Салат | 120 ₽ |
| Суп | 100 ₽ |
| Второе блюдо | 200 ₽ |
| Напиток | 50 ₽ |

## Структура проекта

```
hse-canteen-menu/
├── main.py            # консольная версия
├── app.py             # веб-версия на Streamlit
├── hse-caffe.ipynb    # ноутбук с разработкой и тестированием
├── requirements.txt   # зависимости
└── README.md          # описание проекта
```

Основные элементы кода:

| Элемент | Назначение |
|---|---|
| `menu` | словарь `{день: {категория: [блюда]}}` |
| `PRICES` | цены блюд вне комплекса по категориям |
| `COMPLEX_FULL_PRICE`, `COMPLEX_PARTIAL_PRICE` | цены полного и частичного комплекса |
| `LACTOSE_DISHES` | список блюд, содержащих лактозу |
| `filter_lactose_dishes()` | возвращает блюда, доступные с учётом ограничений |
| `save_order()` | сохраняет итоговую сумму в `сумма.txt` |

## Ограничения

- Меню и цены заданы в коде; для изменения нужно редактировать исходные файлы.
- Наличие лактозы определяется по совпадению названий блюд, поэтому новые блюда нужно вручную добавлять в `LACTOSE_DISHES`.
- Оплата моделируется и не подключена к реальным платёжным системам.
